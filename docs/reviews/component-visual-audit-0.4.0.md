# Fluid DS 0.4.0 component review order

This is the single sequential owner-review queue. It contains all **155 public custom elements** from all 14 package manifests.

## Review loop

1. Codex verifies the current component's component-scoped variables and shared-token fallbacks.
2. Codex fixes and tests any isolation defects before presentation.
3. Codex verifies that every visible Storybook control changes the rendered fixture; controls that cannot meaningfully apply to a multi-fixture comparison are explicitly disabled.
4. Codex opens that component's Storybook story through Chrome DevTools MCP.
5. The owner performs the human visual review.
6. If the owner says **ok**, Codex marks that number Approved and immediately starts the next number.
7. If the owner reports an issue, the current number remains In review until the fix is verified and accepted.

Only one component may be **In review** at a time. Nothing is marked Approved from automated verification alone.
