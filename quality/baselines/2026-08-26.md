## Evidence interpretation

The quality JSON is a source-attribution inventory. A file, story, or fixture
entry does not prove that the element is rendered, the test ran, or all required
behavior is covered. Use the execution evidence and limitations below together.

Each gate was invoked through `scripts/record-readiness-evidence.mjs`. The unique
run directory under `quality/evidence/` retains its exact command, environment,
timestamps, exit code, lockfile hash, working-tree fingerprints, and console log.
The [machine-readable evidence index](2026-08-26.json) records all 32 invocations,
including interrupted setup, failed invocations, diagnostic failures, and reruns.
Raw evidence is local and Git-ignored. Do not delete it until certification
evidence has been deliberately archived elsewhere.

Several runs overlap with documentation, metadata, or generated-artifact edits;
the recorder flags these as `sourceChangedDuringRun`. None is accepted as an
immutable release-candidate run. Performance measurements under concurrent
local workload are diagnostic only.

## Interaction scope correction

The [classification audit](../../docs/reviews/interaction-classification-audit-2026-08-26.md)
adds 21 previously excluded applicable elements. Current figures are 64/103
(62.1 percent), 39 gaps, and 64/155 (41.3 percent) catalog-wide attribution.

No tests were credited merely because a parent component has a passing story.
Section 2 may reuse parent scenarios for children only when the child assertions
and reporting link are explicit. The remaining 52 non-interaction elements
still require their applicable rendering, lifecycle, accessibility, security,
localization, SSR, and visual evidence.

## Newly enforced guard

`apps/a11y/tests/catalog.spec.ts` now requires the expected element to be attached
before running axe. This deliberately exposes the false-positive mappings in
the normal browser gate. Hidden utility hosts remain valid; a missing host does
not. Correct fixtures and action setup will be implemented in the assigned
readiness sections, not bypassed through exclusions.
