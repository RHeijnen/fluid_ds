## The fastest demo

Paste this into a blank `.html` file, that's the whole setup.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fluid-ds/tokens@latest/dist/base.css" />
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fluid-ds/tokens@latest/dist/light.css" />

<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/@fluid-ds/icons@latest/dist/register-defaults.js"
></script>
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/@fluid-ds/components@latest/dist/components/button/define.js"
></script>

<fluid-button>Hello, Fluid</fluid-button>
```

Full walkthrough → **[First component](/getting-started/first-component/)**.

## Why Fluid

<CardGrid stagger>
  <Card title="No framework required" icon="seti:html">
    Real web components. Drop the tags into any HTML page, React, Vue, Angular, Svelte, Solid, plain
    HTML. The browser handles registration.
  </Card>
  <Card title="CDN-first delivery" icon="rocket">
    Load straight from [jsDelivr](https://www.jsdelivr.com), no build step required for evaluation,
    prototypes, or static sites. Bundlers welcome too.
  </Card>
  <Card title="Token-driven theming" icon="setting">
    A small palette of semantic CSS variables drives every component. Override at the brand layer,
    the component layer, or one individual element.
  </Card>
  <Card title="Accessibility first" icon="approve-check">
    Every published element has automated axe coverage. Interactive components add keyboard, focus,
    environment, lifecycle, and recovery contracts; manual assistive-technology review remains a
    separate gate.
  </Card>
</CardGrid>

## Five surfaces

Fluid is documented across five sites that work together:

- **This site**: concepts, tutorials, recipes, per-component pages.
- **[Storybook](/storybook/)**: interactive props/states/a11y
  explorer.
- **[Theme builder](/playground/)**: live token editor that
  exports brand CSS you can drop into your app.
- **[Demos](/demos/)**: sample apps (settings, admin, data table,
  analytics, booking, sprint board, QR studio), plus the same admin
  portal built four times in native HTML, React, Next.js, and Angular.
  It ships a web-app manifest with maskable icons, so it can be added to
  a phone home screen.
- **[Bundle builder](/wizard/)**: pick the components you need and
  generate a custom bundle.
