`<fluid-format-bytes>` formats a byte count as a human-readable, locale-aware
string (comma vs. dot decimal, unit names). Choose binary (`1024`-based: KiB,
MiB) or decimal (`1000`-based: KB, MB), and short / long / narrow display. Built
on `Intl.NumberFormat` with `style: "unit"`, no extra dependencies.

<Demo>
  <fluid-format-bytes value="1500000"></fluid-format-bytes>
</Demo>

## Examples

### Basic

<Demo>
  <fluid-format-bytes value="1500"></fluid-format-bytes>
  <br />
  <fluid-format-bytes value="1500000"></fluid-format-bytes>
  <br />
  <fluid-format-bytes value="1500000000"></fluid-format-bytes>

```html
<!-- 1.5 kB -->

<!-- 1.5 MB -->

```

### Binary base

Use `base="binary"` for IEC units (KiB, MiB).

<Demo>
  <fluid-format-bytes value="1024" base="binary"></fluid-format-bytes>
  <br />
  <fluid-format-bytes value="1048576" base="binary"></fluid-format-bytes>
</Demo>

```html
<fluid-format-bytes value="1024" base="binary"></fluid-format-bytes>
<!-- 1 KiB -->
<fluid-format-bytes value="1048576" base="binary"></fluid-format-bytes>
<!-- 1 MiB -->
```

### Long-form display

<Demo>
  <fluid-format-bytes value="1500000" display="long"></fluid-format-bytes>
</Demo>

```html

<!-- → "1.5 megabytes" -->
```

### Bits

`unit="bit"` outputs bits instead of bytes (Mbps, Gbps for network
speeds).

<Demo>
  <fluid-format-bytes value="125000000" unit="bit"></fluid-format-bytes>
</Demo>

### Locale

An explicit `locale` property or attribute wins. Otherwise the formatter follows
the nearest declared `lang`, including across shadow hosts, then falls back to
English (`en`). Changes to that inherited language update the output, including
after reconnect. This replaces the previous browser-default behavior when no
locale was supplied; no translation-pack import is needed for Intl formatting.

An empty or malformed nearest `lang` is an English boundary. Unsupported language
tags use English as their final fallback. Explicit malformed `locale` values are
not treated as absent: remove the attribute or set the property to `null` to resume
inheritance. Regional and supported numbering/calendar extensions are preserved.

```html
<div lang="fr">
  <fluid-format-bytes value="1500000"></fluid-format-bytes>
</div>
```

Malformed explicit locales, including an empty string, still raise an Intl error;
this component does not silently replace them with another language. Binary
`display="long"` unit names remain English and do not yet have localized plural
grammar. Decimal unit names use Intl; IEC symbols such as KiB remain unchanged.

<Aside type="note">
  Native ancestor language inheritance during SSR remains unverified and is not provided by this
  formatter change. Pass an explicit `locale` for predictable server output; without available
  context the server uses English. This does not promise full locale hydration parity or
  request-scoped translation state.
</Aside>

<Demo>
  <fluid-format-bytes value="1500000" locale="fr-FR"></fluid-format-bytes>
</Demo>

```html
<fluid-format-bytes value="1500000" locale="fr-FR"></fluid-format-bytes>
<!-- → "1,5 Mo" -->
```

## When to use

- File sizes, upload progress, storage limits, bandwidth.
- For plain numeric output, reach for
  [`<fluid-format-number>`](/components/format-number/).
- For "5 minutes ago", use
  [`<fluid-relative-time>`](/components/relative-time/).

## Accessibility

- The element renders inline plain text: no special ARIA needed.
- The unit suffix (kB, MiB, kilobytes) is announced like any other text,
  so screen-reader users hear the same string sighted users read.
