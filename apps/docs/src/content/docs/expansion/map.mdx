A map web component for Fluid: a thin, themed wrapper around
[Leaflet](https://leafletjs.com/) that renders an interactive tile map with
optional markers. Drive it with plain properties so it works from any
framework. Expansion pack.

import { Aside } from "@astrojs/starlight/components";

<Aside type="note">
  Leaflet needs its global stylesheet and a sized container, neither of which
  works inside shadow DOM, so `<fluid-map>` renders in LIGHT DOM. The component
  injects Leaflet's stylesheet once from the CDN (unpkg) at runtime as a `<link>`
  on the document head, so no bundler CSS handling is required: you only need
  `leaflet` installed. To self-host instead, add your own Leaflet stylesheet
  `<link>` (or one carrying `data-fluid-map-leaflet-css`) before the element
  upgrades, and the auto-load is skipped.
</Aside>

## Install

```bash
pnpm add @fluid-ds/map leaflet
```

`leaflet` is a peer you ship. Import the component definition where you use it:

```ts
import "@fluid-ds/map/define/map";
```

## Components

| Tag | Use |
| --- | --- |
| `<fluid-map>` | Themed Leaflet map with markers, move/zoom events, and a labelled region for assistive tech. |

## Use

```html
<fluid-map label="Map of central London"></fluid-map>

<script type="module">
  import "@fluid-ds/map/define/map";

  const map = document.querySelector("fluid-map");
  map.center = [51.505, -0.09];
  map.zoom = 13;
  map.markers = [
    { lat: 51.505, lng: -0.09, label: "Centre" },
    { lat: 51.51, lng: -0.1, label: "North west" }
  ];

  map.addEventListener("fluid-marker-click", (e) => {
    console.log("clicked", e.detail.marker);
  });
  map.addEventListener("fluid-move", (e) => {
    console.log("moved to", e.detail.center, "zoom", e.detail.zoom);
  });
</script>
```

`center`, `zoom`, `markers`, `tile-url`, and `attribution` are all reactive:
update the property and the map re-syncs in place. The container is a labelled
`role="region"`, so give every map a meaningful `label`.

Marker `label` values are plain text. They supply the marker's accessible name,
popup and tooltip; markup in a label is displayed literally. Give each marker
a distinctive name. The explicit `icon.html` and `attribution` APIs still accept
HTML, so supply trusted or sanitized markup there.

### Offline and self-hosted operation

Set `tile-url=""` to disable the tile layer without generating failed tile
requests. For a fully offline map, also serve Leaflet's actual stylesheet
locally before the component upgrades, and use tone pins or local/data-URL
marker images. The default pin images and automatic stylesheet loader use
unpkg; the default tile layer uses OpenStreetMap.

```html
<link rel="stylesheet" href="/vendor/leaflet/leaflet.css" data-fluid-map-leaflet-css />
<fluid-map tile-url="" label="Delivery locations"></fluid-map>
```

Assign markers with `tone: "info"` (or another tone) through the `markers`
property to use inline SVG pins. Removing and reconnecting the element tears
down and recreates its Leaflet instance from the current properties, without
duplicating marker event listeners. If user pan/zoom should survive that
reconnection, mirror `fluid-move` into your application's saved view and supply
the saved `center` / `zoom` properties.

## Custom markers

Each marker can be a plain pin, a semantic **tone** pin, or a fully **custom
icon** (an image or any HTML / emoji). Precedence is `icon` > `tone` > default
pin.

### Semantic tone pins

Give a marker a `tone` (`info` / `success` / `warning` / `danger` / `neutral`)
to render a coloured Fluid pin. Tones read the semantic tokens
(`--fluid-info-base`, `--fluid-danger-base`, etc.), so they re-tint with the
active theme and brand:

```ts
map.markers = [
  { lat: 51.505, lng: -0.09, label: "All good", tone: "success" },
  { lat: 51.51, lng: -0.1, label: "Heads up", tone: "warning" },
  { lat: 51.5, lng: -0.08, label: "Problem", tone: "danger" }
];
```

### Custom image icons

Point `icon.iconUrl` at any image (PNG, SVG, or a data URI). `iconAnchor` is the
pixel of the image that sits on the coordinate and defaults to the bottom centre
(the classic "pin tip"):

```ts
map.markers = [
  {
    lat: 51.505,
    lng: -0.09,
    label: "Head office",
    icon: {
      iconUrl: "/markers/office.png",
      iconRetinaUrl: "/markers/office@2x.png", // optional
      iconSize: [32, 40],
      iconAnchor: [16, 40] // bottom centre
    }
  }
];
```

### HTML / emoji icons

Pass `icon.html` for an emoji, inline SVG, or styled element (rendered via
Leaflet's `divIcon`). It defaults to a transparent, centred box anchored at its
centre:

```ts
map.markers = [
  { lat: 51.505, lng: -0.09, label: "Coffee", icon: { html: "☕" } },
  { lat: 51.51, lng: -0.1, label: "Star", icon: { html: "⭐", iconSize: [40, 40] } },
  {
    lat: 51.5,
    lng: -0.08,
    icon: {
      html: '<span style="font-size:28px">🏠</span>',
      iconSize: [32, 32],
      className: "" // drop the default wrapper class for full control
    }
  }
];
```

The HTML wrapper carries the `fluid-map-marker` class (transparent, centred);
override it with your own `className`, or pass `className: ""` for Leaflet's bare
div.

### Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `center` | - | `[number, number]` | `[51.505, -0.09]` | Map center as `[lat, lng]`. |
| `zoom` | `zoom` | `number` | `13` | Zoom level. |
| `markers` | - | `{ lat, lng, label?, tone?, icon? }[]` | `[]` | Markers to place. `label` becomes a popup + tooltip; `tone` renders a coloured Fluid pin; `icon` is a fully custom image or HTML / emoji marker (wins over `tone`). |
| `tileUrl` | `tile-url` | `string` | OpenStreetMap tiles | Tile layer URL template; an empty string disables tiles. |
| `attribution` | `attribution` | `string` | OpenStreetMap credit | Tile attribution (HTML allowed). |
| `label` | `label` | `string` | `"Map"` | Accessible name for the map region. |

### Events

| Event | Detail | When |
| --- | --- | --- |
| `fluid-marker-click` | `{ marker }` | A marker is clicked or activated with Enter. |
| `fluid-move` | `{ center, zoom }` | The view finishes moving or zooming. |

## Theming

`<fluid-map>` reads the same `--fluid-*` semantic tokens as the rest of the
system for its frame (border, radius, focus ring), so themes flow through
without extra work. Component tokens layer on top for fine-grained control:

| Token | Falls back to | Controls |
| --- | --- | --- |
| `--fluid-map-height` | `24rem` | Viewport height. |
| `--fluid-map-radius` | `--fluid-radius-md` | Viewport corner radius. |
| `--fluid-map-border` | `1px solid --fluid-border-default` | Viewport border. |

The tiles themselves come from your tile provider, so map imagery is not
themed by Fluid. Swap `tile-url` for a dark or styled tile set if you want the
map body to match a dark theme.

## Accessibility and verification scope

The Leaflet viewport supports keyboard panning with arrow keys, zoom controls,
and Enter activation of focusable markers. Keep an equivalent textual list of
locations and actions in the application when the geographical view conveys
essential information. A labelled map alone is not an accessible alternative
for all spatial relationships.

The offline interaction contract checks marker names and event payloads,
pan/zoom, replacement data and reconnect behavior. These automated checks are
not screen-reader certification. Leaflet's internal control strings still need
a complete localization strategy, and representative assistive-technology
review remains a release gate.
