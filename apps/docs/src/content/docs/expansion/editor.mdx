A lightweight WYSIWYG editor for Fluid: a `contenteditable` region exposed as a
multi-line textbox with a roving-tabindex toolbar of formatting toggles. No
external editor library, themable through the same `--fluid-*` tokens as the
rest of the system. Expansion pack.

import { Aside } from "@astrojs/starlight/components";
import EditorDemo from "../../../components/EditorDemo.astro";

The editor below is live and preloaded with content: select some text, use the
toolbar (or the arrow keys inside it), and watch the sanitized HTML value
update underneath.

## Install

```bash
pnpm add @fluid-ds/editor
```

Import only the pieces you use:

```ts
import "@fluid-ds/editor/define/rich-text-editor";
```

## Components

| Tag                        | Use                                                                                                |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| `<fluid-rich-text-editor>` | Accessible contenteditable WYSIWYG with a Bold / Italic / Underline / list / link / clear toolbar. |

## Use

```html
<fluid-rich-text-editor
  label="Compose a note"
  placeholder="Start typing your note..."
></fluid-rich-text-editor>
```

Set initial content (and read edits back) with the `value` property, which holds
the editor's HTML:

```html
<fluid-rich-text-editor id="bio" label="Author bio"></fluid-rich-text-editor>

<script type="module">
  import "@fluid-ds/editor/define/rich-text-editor";

  const editor = document.getElementById("bio");
  editor.value = "<p>Hello, <strong>world</strong>.</p>";
  editor.addEventListener("fluid-change", (e) => {
    console.log(e.detail.value); // current HTML on every edit
  });
</script>
```

## API

### Properties

| Property                | Type      | Default              | Description                                                                                                                                       |
| ----------------------- | --------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`                 | `string`  | `""`                 | The editor content as an HTML string. Reading it returns the live HTML; setting it replaces the editable content.                                 |
| `label`                 | `string`  | `"Rich text editor"` | Accessible name for the editable textbox.                                                                                                         |
| `placeholder`           | `string`  | `""`                 | Hint shown while the editor is empty.                                                                                                             |
| `readOnly` / `readonly` | `boolean` | `false`              | Keep the textbox selectable and focusable but prevent editing and disable formatting controls. Programmatic `value` assignment remains available. |

### Events

| Event          | Detail              | Description                                                                                                                                                      |
| -------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fluid-change` | `{ value: string }` | Fires once per content mutation with sanitized HTML. A formatting command and its native input do not emit duplicates. Programmatic assignment does not emit it. |

### Toolbar

The toolbar is a `role="toolbar"` group with roving tabindex: Tab moves into and
out of it, while the arrow keys (plus Home and End) move between buttons. The
toggle buttons (Bold, Italic, Underline, Bullet list, Numbered list) reflect
`aria-pressed` from the current selection. Link and Clear formatting are action
buttons. Every button carries an `aria-label`, a minimum target size, and a
visible focus ring.

Moving into the toolbar preserves the editor selection for the formatting
command. Pointer activation keeps that selection, and commands return focus to
the textbox. Read-only content remains accessible for reading and copying.
Selection capture includes containing shadow roots when the browser provides
`Selection.getComposedRanges()`. The older API fallback accepts only ranges
whose endpoints are both inside this editor; it does not guess retargeted shadow
endpoints. Replacing `value` discards the old saved selection. Assigning the same
sanitized HTML without replacing the DOM preserves it.
Backward selections retain their direction, including after a canceled link
prompt. Sanitization and read-only rollback discard a saved range when they
replace the editable DOM.
Assigned, pasted, and edited HTML is sanitized before it is exposed in a change
event. This is not a substitute for server-side validation when storing or
rendering user-generated content elsewhere.

### Verification scope

The 2026-08-26 targeted suite contains 43 test cases, executed separately in
Chromium, Firefox and WebKit. Native browser keyboard input establishes the
selection for formatting, link creation and nested-shadow-root restoration.
Controlled API tests cover the legacy selection fallback and rejected ranges;
they are not proof of support for older browsers. Synthetic paste tests provide
an explicit HTML payload and verify sanitization, actual insertion and one
change event. They do not verify operating-system clipboard permissions or a
trusted paste gesture. Coverage percentages are measured separately from these
case counts. Manual assistive-technology review remains outstanding.

## Theming

Every styled property reads a component-scoped `--fluid-editor-*` token that
falls back to a main semantic token, so you can retheme one instance, every
editor, or the whole brand without touching the component. Setting a semantic
token (for example `--fluid-accent-base`) flows through automatically.

```html
<fluid-rich-text-editor
  style="--fluid-editor-toolbar-bg: #1e1b4b; --fluid-editor-radius: 1rem;"
  label="Themed editor"
></fluid-rich-text-editor>
```

## When to use

- A comment box, note field, or simple article body where users need basic
  formatting (bold, italic, lists, links) without the weight of a full editor
  framework.
